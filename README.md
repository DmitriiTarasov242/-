# Expense Tracker (Трекер расходов)
**Автор:** [Ваше Имя Фамилия]
**Язык:** Python 3.x

## Описание программы
Простое десктопное приложение для учета личных финансов. Позволяет добавлять расходы по категориям и датам, фильтровать их по категориям и датам, а также подсчитывать общую сумму затрат за выбранный период. Все данные сохраняются в локальный файл `expenses.json`.

## Технологии
*   **Python** — язык программирования.
*   **Tkinter** — стандартная библиотека для создания графического интерфейса (GUI).
*   **tkcalendar** — сторонняя библиотека для удобного выбора дат.
*   **JSON** — формат хранения данных.
*   **Git** — система контроля версий.

## Установка зависимостей (для пользователей)
Для работы программы требуется установить библиотеку `tkcalendar`. Откройте терминал/командную строку и выполните команду:
`pip install tkcalendar`

## Как использовать программу

### 1. Добавление расхода:
1.  Введите сумму в поле **"Сумма"**.
2.  Выберите категорию из выпадающего списка **"Категория"**.
3.  Выберите дату в календаре **"Дата"**.
4.  Нажмите кнопку **"Добавить расход"**. Запись появится в таблице.

### 2. Фильтрация по категории:
1.  Выберите интересующую вас категорию в поле **"Фильтр по категории"**.
2.  Нажмите кнопку **"Применить фильтр"**. В таблице останутся только расходы выбранной категории.
3.  Чтобы вернуть полный список, выберите вариант **"Все"** и снова нажмите кнопку.

### 3. Подсчет суммы за период:
1.  Выберите дату начала периода в поле слева от кнопки подсчета.
2.  Выберите дату окончания периода в поле справа.
3.  Нажмите кнопку **"Подсчитать сумму"**. Результат отобразится под кнопкой.
